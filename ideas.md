# Model Release Radar — Design Direction

## Three possible directions

### 1. Gate Room
**Very Brief Intro:** A cold, monochrome release-control room where every signal feels like part of an audit trail. The interface makes the decision trace more prominent than chart decoration.

**Probability:** 0.08

### 2. Signal Ledger
**Very Brief Intro:** A compact evidence ledger with restrained typography, structured rows, and dense technical summaries. The mood is closer to a signed release document than a dashboard.

**Probability:** 0.04

### 3. Cobalt Watch
**Very Brief Intro:** A high-contrast operations surface with cobalt as a selective signal color and dramatic contrast between passing and held candidates.

**Probability:** 0.06

## Chosen direction — Gate Room

### Design Movement

**Release-control minimalism** combines a black-and-white operational interface with product-gallery clarity. It is deliberately distinct from Solar Ops Planner’s warm planning desk.

### Core Principles

1. **A decision must be traceable.** Every simulated outcome maps to named evidence gates.
2. **Cobalt means signal, not decoration.** It appears only in active threshold controls and evidence markers.
3. **Audit beats analytics theatre.** Hard edges, calm panels, and neutral numbers keep attention on the decision.
4. **Synthetic inputs stay explicit.** No visual treatment implies a real company approval system.

### Color Philosophy

Cold off-white, graphite, and true black establish a controlled review environment. Cobalt is the narrow signal channel and does not function as a broad brand wash. Success and hold labels are compact, descriptive states rather than large colored dashboard surfaces.

### Layout Paradigm

The page is a **policy console**: a narrow threshold column governs a wide evidence-and-decision canvas. The hero is a black release band; below it, tabular decision traces and audit-like panels replace a generic KPI dashboard.

### Signature Elements

1. **Threshold matrix label:** a subtle audit stamp inside the decision panel.
2. **Square evidence markers:** compact cobalt signal points instead of rounded status ornaments.
3. **Decision trace rows:** named gates with decision-relevant detail and a pass/review state.

### Interaction Philosophy

Threshold changes update the decision immediately. The user should be able to explain why a run changed from release to review without reading implementation code.

### Animation

Use short 160–180ms opacity and transform transitions only. Values may cross-fade; no animated charts or decorative looping motion.

### Typography System

`DM Sans` 700 gives the decision headings a dense editorial tone; `Manrope` handles UI text. Tabular values use a system monospace so thresholds and measured signals read as operational material.

### Brand Essence

**A transparent release-decision sandbox for AI/ML learners who want to show operational judgment, not just model metrics.**

**Personality:** exact, skeptical, composed.

### Brand Voice

Headlines state a decision; helper copy identifies its limits.

> "Release only when the evidence can answer back."

> "One candidate. Four gates. A decision you can inspect."

### Wordmark & Logo

The symbol is a black two-panel gate with a cobalt dot moving through its central threshold. The wordmark uses a compact `MODEL / RELEASE` lock-up with technical spacing and no copied branding.

### Signature Brand Color

**Signal Cobalt — #0064E0.**
